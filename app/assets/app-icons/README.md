# Ícones das aplicações

Recursos incluídos no pacote para identificar as aplicações na interface, sem pedidos
a Google Favicons ou a outros serviços de imagens durante o arranque. Os nomes,
marcas e ícones pertencem aos respetivos titulares; não indicam afiliação ao LusoToolkit.
Não se altera a licença de cada recurso. Ficheiros recolhidos em 18/10/2026.

Os ícones de ZoneSoft Converter 2.3.8, Auditor de Rede 2.1, LigaBD, Network Scanner
5.1.3 e Acesso remoto foram extraídos, apenas por leitura dos recursos, dos cinco
executáveis já fornecidos pelo mantenedor. ZSTools usa o recurso do ZSTools.exe
do pacote oficial anteriormente verificado. Não foram executados, instalados ou alterados.

Estes recursos visuais não mudam o comportamento de instalação, acesso remoto ou
limpeza dos portáteis e não acrescentam aplicações ao catálogo.
